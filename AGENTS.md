# Engineering rules

These apply to every change in this repository, without exception.

## Authorship

- All production code is authored under **Anubhav Bhatia**.
- Do not add AI or Cursor authorship: no co-author trailers, no "generated by"
  markers, no tool attribution in commits, code, or documentation.

## Honesty

- Never state a benchmark, test result, or metric that has not actually been
  produced by a run that can be reproduced. Unmeasured means unstated.
- Never describe a capability as implemented when it is not. Planned work is
  labelled as planned.

## Scope

- This repository is **MyVista LLM Fabric** only. All code generated for this
  project belongs here.
- Do not clone, copy from, merge into, or otherwise modify any other project.

## Specification

- The project engineering constitution is the permanent architecture and
  engineering specification. Once committed it lives at `docs/constitution.md`
  and takes precedence over inference, convention, and this file.
- `ARCHITECTURE.md` must be kept consistent with it, and must distinguish what
  is built from what is proposed.
